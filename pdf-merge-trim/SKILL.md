# PDF 智能合并与白边裁剪

自动裁剪 PDF 白边、统一页面尺寸、合并多个文件。

## 依赖

- PyMuPDF（`fitz`）：唯一必须依赖，承担全部 PDF 处理工作

安装：
```bash
pip install PyMuPDF
```

> **注意**：旧版本依赖 pypdfium2，现已移除，仅需 PyMuPDF 即可。

## 使用方法

### 命令行调用

```bash
python scripts/merge_trim.py \
  --source <PDF源目录> \
  [--keyword <文件名关键词>] \
  [--width <目标宽度mm>] \
  [--height <目标高度mm>] \
  [--output <输出文件路径>] \
  [--dpi <渲染DPI>] \
  [--threshold <白色阈值>] \
  [--margin <安全边距%>] \
  [--max-size <最大文件MB>] \
  [--no-trim]
```

### 参数说明

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `--source` / `-s` | 是 | — | 包含 PDF 文件的源目录（递归搜索子目录） |
| `--keyword` / `-k` | 否 | — | 文件名筛选关键词（大小写不敏感），不填则处理所有 PDF |
| `--width` / `-W` | 否 | 100 | 目标页面宽度（毫米） |
| `--height` / `-H` | 否 | 100 | 目标页面高度（毫米） |
| `--output` / `-o` | 否 | 自动生成 | 输出 PDF 文件路径（默认保存到源目录） |
| `--dpi` | 否 | 150 | 像素扫描白边时的渲染 DPI（值越高越精确但越慢） |
| `--threshold` | 否 | 240 | 白色阈值 0–255（越低裁剪越激进，建议 220–245） |
| `--margin` | 否 | 1 | 安全边距（百分比），防止内容被裁剪 |
| `--max-size` | 否 | 200 | 跳过超过此大小（MB）的文件；0 表示不限制 |
| `--no-trim` | 否 | — | 加此标志则跳过白边裁剪，仅合并并统一页面尺寸 |
| `--add-fba-text` | 否 | — | 对纯图片页面（无文字层）添加隐藏 FBA 文字（渲染模式3，不可见但可选中复制） |
| `--fba-font-size` | 否 | 10 | FBA 隐藏文字字体大小（点） |
| `--fba-bottom-mm` | 否 | 8.0 | FBA 隐藏文字距页面底部距离（毫米），水平居中 |

### 快速示例

```bash
# 合并所有含 "FBA" 的标签，100x100mm
# 关键词用 "FBA" 而非 "FBA标签"，确保 FBA15XXXXXX-数字.pdf 格式的文件也被匹配
python scripts/merge_trim.py \
  --source "C:\Users\Administrator\Desktop\标签文件夹" \
  --keyword "FBA" \
  --width 100 \
  --height 100

# 仅合并，不裁剪白边
python scripts/merge_trim.py \
  --source "D:\Labels" \
  --no-trim \
  --width 100 \
  --height 100

# 调高 DPI 提升扫描件裁剪精度
python scripts/merge_trim.py \
  --source "D:\Scanned" \
  --dpi 200 \
  --threshold 230

# 对纯图片 FBA 标签添加隐藏 FBA 文字（便于软件读取）
python scripts/merge_trim.py \
  --source "C:\FBA标签" \
  --keyword "FBA" \
  --add-fba-text \
  --width 100 \
  --height 100

# 自定义 FBA 文字位置和大小
python scripts/merge_trim.py \
  --source "C:\FBA标签" \
  --add-fba-text \
  --fba-font-size 12 \
  --fba-bottom-mm 10
```

## 处理流程

1. **扫描 PDF**：递归搜索源目录下所有 PDF 文件，自动排除本工具产生的临时文件和合并结果
2. **关键词筛选**（可选）：文件名包含指定关键词才会被处理
3. **逐文件处理**：
   - **方法 A（矢量边界）**：先用 fitz 提取文字块、路径、图片的边界矩形，快速准确
   - **方法 B（像素扫描）**：方法 A 无效时降级为渲染位图后逐像素扫描，适合扫描件
   - 加安全边距，缩放到目标尺寸并垂直居中
   - **FBA 隐藏文字**（仅当 `--add-fba-text` 启用）：从文件名提取 FBA 号，对无文字的页面添加隐藏文字层（渲染模式3，距底部8mm居中）
4. **合并**：所有处理好的页面合并为一个 PDF，使用 `garbage=4` 压缩去冗余
5. **输出**：保存到指定路径，临时文件自动清理

## 白边检测策略

```
矢量内容检测（文字 + 路径 + 图片）
    ↓ 成功 → 使用矢量边界（快速、精确）
    ↓ 失败
像素扫描（渲染为灰度位图后逐像素）
    ↓ 成功 → 使用像素边界（适合扫描件）
    ↓ 失败
使用整页（不裁剪，保留全部内容）
```

## 排除规则

以下文件会被自动跳过：
- 文件名包含 `_合并_`
- 文件名包含 `_test.`
- 文件名包含 `_tmp_`
- 文件名包含 `merged.pdf`、`merged(`
- 文件名包含 `_cropped.pdf`（旧版本残留临时文件）
- 文件大小超过 `--max-size`（默认 200MB）

## 注意事项

- 矢量 PDF（含嵌入文字/路径）优先用矢量检测，速度快且精确
- 扫描件（纯图片 PDF）自动降级为像素扫描，可适当提高 `--dpi` 改善精度
- `--threshold` 默认 240，如遇浅色背景误裁可适当调低（如 220）
- 输出文件大小取决于原始文件内容类型（矢量远小于图片）
